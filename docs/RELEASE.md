# pdcli v0.1

This is the first release of the `pdcli` tool. There will be a lot of features missing (such as photos and Computers), so stand steady for these items in the next release. 

This is only for linux. If you want to attempt this for any other operating system, go ahead and try, but I likely won't support it. `proton-drive` and `proton-sdk-rs2` for any other operating system I can support though. 

## Usage

Just download this to anywhere, make it executable `chmod +x {pdcli_location}` and try running this with `pdcli mount {mount_location}`.
